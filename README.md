# 日语会話コーチ

一个面向中文学习者的日语对话练习工具。

## 目标功能

- 日语自由聊天，AI 根据上下文继续对话
- 每次回答同时纠正用户的日语
- 指出「错误」和「语法没错但不自然」
- 给出更自然、更口语化的版本
- 用中文解释语法
- 解释重要动词：基本意思、常用搭配、使用场景、语气，以及相近动词区别
- 日常 / 职场 / 外贸 / 面试模式
- 移动端适配
- 浏览器本地保存练习记录

## 当前版本

当前仓库包含一个可以直接打开的前端原型。它暂时使用本地演示纠错规则，没有把 API Key 放在浏览器里。

下一步接入真正的 AI 时，应使用后端或 Serverless API，**不要把模型 API Key 直接写进前端 JavaScript**。

## AI 教练的核心行为

每次用户输入日语后：

1. 先自然地回应用户，让对话继续。
2. 判断原句是否有语法错误。
3. 即使语法正确，也判断是否符合自然口语、职场语境和常见搭配。
4. 给出自然版本。
5. 用简明中文解释哪里错、为什么不自然。
6. 对重要动词说明：
   - 基本意思
   - 常见搭配
   - 一般用于什么场景
   - 与相近动词的区别
7. 最后提出一个自然的追问，让用户继续用日语回答。

目标不是“把所有句子改得很正式”，而是让中文母语者逐渐说出自然、常用的日语。
